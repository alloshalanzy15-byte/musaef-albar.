مشروع مسعف البر الذكي
======================

تشغيل المشروع على ويندوز:
1) فك ضغط الملف.
2) افتح مجلد musaef_albar في VS Code.
3) ثبّت إضافة Live Server من متجر إضافات VS Code (مرة واحدة).
4) افتح index.html ثم اضغط بزر الفأرة الأيمن واختر Open with Live Server.
5) سيفتح التطبيق في المتصفح.

ملاحظات:
- لا تفتح index.html بالنقر المزدوج إذا أردت اختبار التثبيت والعمل دون اتصال؛ استخدم localhost أو استضافة HTTPS.
- لتثبيته على أندرويد: ارفع المجلد إلى استضافة HTTPS، ثم افتح الرابط في Chrome واختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".
- زر الكاميرا يفتح كاميرا الجهاز/منتقي الصور، ولا يحلل الصورة آليًا.
- البوصلة تعتمد على دعم الجهاز والمتصفح ومستشعر الاتجاه.
- البحث عن أقرب مستشفى يفتح خرائط Google ويحتاج الإنترنت.
- بيانات الإسعافات توعوية وليست تشخيصًا أو بديلًا عن التدريب الطبي أو الطوارئ.
- راجع أرقام الطوارئ وتوفرها محليًا قبل التسليم الرسمي، فقد تختلف التغطية حسب المنطقة.
